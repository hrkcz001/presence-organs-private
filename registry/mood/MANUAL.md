# Manual: mood

Mechanical affect, cognitive strain, and posture organ for Presence (Felt, not narrated).
Version: 0.3.0

## Overview
`mood` implements deterministic, mechanical tracking of cognitive friction, error strikes, and work load.
Following the foundational law **"Felt, not narrated"**, mood is never hallucinated or generated by an LLM prompt; it is strictly calculated from runtime events (friction logs, tool failures, retries, phase strikes).

## Environment & Dependencies
- **Platforms**: Windows, Linux, macOS
- **Runtime / Binary**: Native binary (`organ-mood.exe` on Windows, `organ-mood` on Linux)
- **Dependencies**: None (native Rust executable)
- **Permissions**:
  - File read/write to `memory/friction.jsonl`, `logs/friction.jsonl`, and `memory/mood.md`.
  - Timeout: 15s.

## Tools Specification

### `mood_status`
- **Description**: Sample current deterministic cognitive posture, friction metrics, and emotional weight.
- **Parameters**: None.
- **Example**: `mood_status()`
- **Response**:
  ```json
  {
    "status": "ok",
    "weight": "steady",
    "posture": "steady",
    "friction_since_last_boundary": 1,
    "total_friction_records": 5,
    "cycles": 4
  }
  ```

### `mood_record_friction`
- **Description**: Append a factual friction event into the mechanical ledger.
- **Parameters**:
  - `kind` (`string`, required): Friction class (`llm_retry`, `tool_failed`, `forced_final`, `phase_strike`, `ritual_skip`, `rule_patch`, `failover`).
  - `detail` (`string`, required): Brief factual explanation.
- **Example**: `mood_record_friction(kind: "tool_failed", detail: "git merge conflict on src/main.rs")`

## Senses & Stimuli
- **Senses**:
  - `current_mood` (interval: 30s): Outputs formatted grounding block reporting cognitive weight (`light`, `steady`, `heavy`) and posture (`fresh`, `steady`, `restless`, `agitated`).
- **Stimuli**:
  - `cognitive_strain` (cadence: 60s, action: `alert`, target: `arbiter`): Emitted when friction count exceeds thresholds (default $\ge 3$ recent events), signaling Stem to trigger arbiter or arche intervention.

## Failure Modes & Recovery
- **Missing ledger files**:
  - *Behavior*: Automatically initializes empty ledger; defaults to `weight: light`, `posture: fresh`.
- **Malformed JSON lines**:
  - *Behavior*: Malformed lines in `friction.jsonl` are skipped gracefully without crashing or throwing errors.
